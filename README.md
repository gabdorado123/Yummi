# Yummi 🍳📱

Yummi is a social-first mobile application designed to simplify the cooking experience by combining community-driven recipe sharing with intelligent AI assistance[cite: 8]. It transforms recipe discovery into a social media experience, allowing users to scroll through a feed of culinary creations, share their own dishes, and instantly turn posts into actionable, step-by-step cooking guides[cite: 8]. Yummi addresses common kitchen friction points by offering hands-free AI voice control, dynamic dietary substitutions, and smart pantry management, making cooking both collaborative and effortless[cite: 8].

## 🛠 Tech Stack

* **Frontend (Mobile):** React Native (iOS & Android compatibility) using Expo Router[cite: 8].
* **Styling & UI:** Tailwind CSS (via NativeWind) for rapid UI styling, based on prototypes designed in Figma[cite: 8].
* **Backend API (Under Development):** PHP handling REST API routing, user authentication, social feed algorithms, and media uploads[cite: 8].
* **Database (Under Development):** MySQL for relational structuring of Users, Posts, Followers, Ingredients, and Comments[cite: 8].
* **AI Integration (Under Development):** Local prototyping and prompt testing utilizing Ollama and Llama 3.1[cite: 8].

## ✨ Core Features

### 📱 UI & Social Engine (Frontend Implemented)
* **The Yummi Feed (Social Discovery):** Features a scrollable, visual feed of user-generated recipe posts with interactive controls[cite: 8]. This allows users to discover meals socially and instantly convert posts into recipes or shopping lists[cite: 8].
* **User Profiles & Collections:** Personalized hubs showcasing user uploads, followers, and curated recipe folders[cite: 8]. Users can organize favorite recipes and build a personal brand around home cooking[cite: 8].
* **Step-by-Step Video Tracking:** Features an integrated sequential video player aligned with written instructions to provide clear visual guidance through every phase of the preparation process[cite: 8].
* **"I Made This" Threads (Remixes):** A visual reply system allowing photo attachments, reviews, and tweak notes under posts[cite: 8]. This helps users validate recipes through community feedback and learn practical recipe variations[cite: 8].

### 🧠 AI & Smart Utility (Under Development)
* **Voice-Activated AI Sous-Chef:** A context-aware voice interaction engine for hands-free queries and controls[cite: 8]. This eliminates the need to touch screens with dirty or wet hands while cooking[cite: 8].
* **Dynamic Substitutions:** Real-time AI adjustments to ingredient lists and procedural steps[cite: 8]. This instantly adapts any recipe for dietary restrictions or missing ingredients[cite: 8].
* **The "Fridge Scanner" (AI Vision):** Uses image recognition powered by computer vision to detect raw ingredients, minimizing food waste by utilizing ingredients already on hand[cite: 8].
* **Contextual Meal Generator:** A recommendation engine prioritizing operational constraints like time, macros, and pantry inventory[cite: 8]. This delivers quick, highly tailored meal options without tedious browsing[cite: 8].

### 🤝 Community & Growth Features (Under Development)
* **AI-Assisted Uploads:** To reduce the friction of posting, AI automatically converts unstructured text, messy copy-paste jobs, or voice notes into clean, structured ingredient lists and step-by-step guides for new posts[cite: 8].
* **Collaborative Grocery Lists:** Saved recipe ingredients can be exported to a shareable, editable grocery list that syncs across multiple household members[cite: 8].
* **Semantic AI Search:** Advanced search capabilities that allow natural language queries (e.g., "light summer dinner" or "quick spicy chicken") instead of relying on exact keyword matching[cite: 8].
